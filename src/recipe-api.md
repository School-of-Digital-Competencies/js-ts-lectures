# Условие задачи: Рецепты

Вы разрабатываете веб-приложение для управления рецептами в браузере, которое позволяет пользователям просматривать и искать рецепты на основе различных критериев. Приложение должно взаимодействовать с внешним API, предоставляющим информацию о рецептах.

Обязательно использовать API по адресу https://dummyjson.com/docs/recipes для реализации данной задачи.

## Задача:

### Получение всех рецептов:

Реализуйте функцию, которая будет запрашивать все доступные рецепты с API. Функция должна принимать параметры для настройки запроса, такие как:

- limit — максимальное количество рецептов, которые нужно вернуть (по умолчанию 30).
- sortBy — поле, по которому будет производиться сортировка (например, по времени приготовления).
- order — порядок сортировки (по возрастанию или убыванию).

### Получение рецепта по ID:

Реализуйте функцию, которая будет запрашивать конкретный рецепт по его уникальному идентификатору (ID). Функция должна возвращать все детали рецепта.

### Поиск рецептов:

Реализуйте функцию, которая будет принимать строку поиска и возвращать список рецептов, соответствующих этому запросу. Поиск должен быть по названию рецепта или его ингредиентам.

### Обработка ошибок:

Все функции должны корректно обрабатывать возможные ошибки, возникающие при выполнении запросов к API, и выводить соответствующие сообщения в консоль.

### Пример использования:

В конце вашего кода добавьте пример использования этих функций, который:

- Получает и выводит все рецепты, отсортированные по времени приготовления в порядке убывания.
- Выполняет поиск рецептов по ключевому слову "курица" и выводит результаты.

## Ожидаемые результаты:

- Пользователь сможет видеть список всех доступных рецептов с возможностью сортировки.
- Пользователь сможет получать информацию о конкретном рецепте по его ID.
- Пользователь сможет искать рецепты по ключевым словам и получать соответствующие результаты.
- В случае ошибок при запросах пользователю будет предоставлена информация о том, что пошло не так.
