# Условие задачи: Корзина покупок для интернет-магазина

Вы разрабатываете приложение для интернет-магазина, которое позволяет пользователям заказывать продукты из меню. Ваша задача состоит в реализации функциональности корзины покупок, которая будет управлять добавлением и удалением товаров, а также отображать информацию о текущем заказе.

## Продукты

Создайте структуру, представляющую отдельный продукт, которая должна содержать название и цену продукта.

## Корзина покупок

Создайте структуру, представляющую корзину покупок. Эта структура должна включать:

- Массив для хранения добавленных продуктов.
- Метод для добавления продукта в корзину.
- Метод для удаления продукта из корзины по указанному индексу, с обработкой ошибок для недействительных индексов.
- Геттер для получения общей стоимости всех продуктов в корзине.
- Метод для отображения информации о текущих товарах в корзине и их общей стоимости.

## Меню

Создайте структуру, представляющую меню с доступными продуктами. Эта структура должна включать:

- Массив с предустановленными продуктами.
- Метод для получения продукта по индексу, с обработкой ошибок для недействительных индексов.
- Метод для отображения списка доступных продуктов.

# Основной процесс

Реализуйте основной процесс, который будет выполнять следующие действия:

- Отобразить меню с доступными продуктами.
- Запросить у пользователя номер продукта, который он хочет добавить в корзину.
- Позволить пользователю завершить заказ, введя специальный код (например, -1).
- Добавить выбранный продукт в корзину и уведомить пользователя об этом.
- В конце, после завершения заказа, отобразить содержимое корзины и общую стоимость.

## Пример работы программы:

- Пользователь видит меню с доступными продуктами и их ценами.
- Пользователь вводит номер продукта для добавления в корзину.
- Программа добавляет продукт в корзину и уведомляет пользователя.
- Пользователь может продолжать добавлять продукты или завершить заказ.
- После завершения заказа программа выводит содержимое корзины и общую стоимость заказа.

### Примечания:

- Обработайте возможные ошибки, такие как ввод недопустимого номера продукта.
- Обеспечьте чистоту и читаемость кода, используя методы для управления продуктами и корзиной.
