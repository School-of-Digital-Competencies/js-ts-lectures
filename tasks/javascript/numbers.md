# JavaScript Numbers Tasks

[Back to all tasks](../../README.md)

Sum of Numbers: Write a function that takes an array of numbers and returns their sum. For example, for the array [1, 2, 3, 4], the result should be 10.

Find Maximum Number: Create a function that takes an array of numbers and returns the maximum number from that array. For example, for the array [5, 2, 9, 1], the result should be 9.

Check Evenness: Write a function that takes a number and returns true if the number is even and false if it is odd. For example, for the number 4, the result should be true, and for 5, it should be false.

Factorial of a Number: Create a function that calculates the factorial of a given number. For example, for the number 5, the result should be 120 (5! = 5 × 4 × 3 × 2 × 1).

Check Prime Number: Write a function that takes a number and returns true if the number is prime and false otherwise. For example, for the number 7, the result should be true, and for 8, it should be false.

Sort Array: Create a function that takes an array of numbers and returns a new array sorted in ascending order. For example, for the array [3, 1, 4, 2], the result should be [1, 2, 3, 4].

Power Function: Write a function that takes two numbers: a base and an exponent, and returns the result of raising the base to the exponent. For example, for the base 2 and exponent 3, the result should be 8.

Calculate Average: Create a function that takes an array of numbers and returns their average. For example, for the array [2, 4, 6, 8], the result should be 5.

Generate Random Number: Write a function that returns a random integer within a specified range (inclusive). For example, for the range from 1 to 10, the function should return a random number from 1 to 10.

Convert Celsius to Fahrenheit: Create a function that takes a temperature in Celsius and returns its equivalent in Fahrenheit. The conversion formula is F = C \* 9/5 + 32. For example, for 0 degrees Celsius, the result should be 32 degrees Fahrenheit.

Convert Fahrenheit to Celsius: Create a function that takes a temperature in Fahrenheit and returns its equivalent in Celsius. The conversion formula is C = (F - 32) \* 5/9. For example, for 32 degrees Fahrenheit, the result should be 0 degrees Celsius.

Calculate Percentage: Write a function that takes two numbers: a total amount and a percentage, and returns the result of calculating the percentage of the total amount. For example, for a total of 100 and a percentage of 25, the result should be 25.

Calculate Square Root: Create a function that takes a number and returns its square root. For example, for the number 16, the result should be 4.

Calculate Absolute Value: Write a function that takes a number and returns its absolute value. For example, for the number -5, the result should be 5.

Round to Nearest Integer: Create a function that takes a number and returns its rounded value to the nearest integer. For example, for the number 4.7, the result should be 5.

Round to Specified Precision: Write a function that takes a number and the number of decimal places, and returns its rounded value to the specified precision. For example, for the number 4.756 and precision 2, the result should be 4.76.

Calculate Difference Between Two Numbers: Create a function that takes two numbers and returns their difference. For example, for the numbers 10 and 5, the result should be 5.

Calculate Sum of Squares: Write a function that takes an array of numbers and returns the sum of their squares. For example, for the array [1, 2, 3], the result should be 14 (1² + 2² + 3²).

Calculate Product of Numbers: Create a function that takes an array of numbers and returns their product. For example, for the array [1, 2, 3], the result should be 6 (1 × 2 × 3).

Calculate Distance Between Two Points: Write a function that takes the coordinates of two points (x1, y1) and (x2, y2) and returns the distance between them. The formula for calculating the distance is √((x2 - x1)² + (y2 - y1)²). For example, for the points (1, 2) and (4, 6), the result should be 5.

Check Palindrome Number: Write a function that takes a number and returns true if it is a palindrome (the same backward as forward) and false otherwise. For example, for the number 121, the result should be true, and for 123, it should be false.

Find GCD (Greatest Common Divisor): Create a function that takes two numbers and returns their greatest common divisor. For example, for the numbers 8 and 12, the result should be 4.

Find LCM (Least Common Multiple): Write a function that takes two numbers and returns their least common multiple. For example, for the numbers 4 and 5, the result should be 20.

Check Armstrong Number: Create a function that determines if a number is an Armstrong number (a number that is equal to the sum of its own digits each raised to the power of the number of digits). For example, for the number 153, the result should be true (1³ + 5³ + 3³ = 153).

Count Digits in a Number: Write a function that takes a number and returns the count of its digits. For example, for the number 12345, the result should be 5.

Reverse a Number: Create a function that takes a number and returns it reversed. For example, for the number 12345, the result should be 54321.

Generate Fibonacci Sequence: Write a function that takes a number n and returns the first n numbers in the Fibonacci sequence. For example, for n = 5, the result should be [0, 1, 1, 2, 3].

Calculate Compound Interest: Create a function that calculates the compound interest given the principal amount, rate of interest, number of times interest applied per time period, and the number of time periods. For example, for a principal of 1000, rate 5%, compounded 4 times a year for 5 years, the result should be calculated accordingly.

Find the Median of an Array: Write a function that takes an array of numbers and returns the median value. For example, for the array [3, 1, 2, 5, 4], the result should be 3.

Check for Perfect Number: Create a function that checks if a number is a perfect number (a number that is equal to the sum of its proper divisors). For example, for the number 6, the result should be true (1 + 2 + 3 = 6).

Count Vowels in a Number: Write a function that takes a number (converted to a string) and returns the count of vowels in its string representation. For example, for the number 12345, the result should be 0.

Find the Mode of an Array: Create a function that takes an array of numbers and returns the mode (the number that appears most frequently). For example, for the array [1, 2, 2, 3, 4], the result should be 2.

Calculate the Sum of Digits: Write a function that takes a number and returns the sum of its digits. For example, for the number 123, the result should be 6 (1 + 2 + 3).

Check if a Number is a Perfect Square: Create a function that checks if a given number is a perfect square. For example, for the number 16, the result should be true, and for 15, it should be false.

Convert Decimal to Binary: Write a function that converts a decimal number to its binary representation. For example, for the number 10, the result should be 1010.

Convert Binary to Decimal: Create a function that converts a binary number (as a string) to its decimal equivalent. For example, for the binary string '1010', the result should be 10.

Find the Range of an Array: Write a function that takes an array of numbers and returns the range (the difference between the maximum and minimum values). For example, for the array [3, 1, 4, 1, 5], the result should be 4 (5 - 1).

Calculate the Harmonic Mean: Create a function that calculates the harmonic mean of an array of numbers. For example, for the array [1, 2, 3], the harmonic mean should be 1.636.

Check if Two Numbers are Coprime: Write a function that checks if two numbers are coprime (their greatest common divisor is 1). For example, for the numbers 8 and 15, the result should be true.

Generate a Random Floating-Point Number: Create a function that generates a random floating-point number within a specified range (inclusive). For example, for the range from 1.0 to 10.0, the function should return a random floating-point number between 1.0 and 10.0.
