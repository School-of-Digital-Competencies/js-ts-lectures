# JavaScript Strings Tasks

[Back to all tasks](../../README.md)

Reverse a String: Write a function that takes a string and returns it reversed. For example, for the input "hello", the output should be "olleh".

Check for Palindrome: Create a function to check if a string is a palindrome (reads the same backward as forward). For example, "racecar" should return true, while "hello" should return false.

Count Vowels in a String: Write a function that counts the number of vowels in a given string. For example, for the string "hello world", the result should be 3.

Count Consonants in a String: Create a function that counts the number of consonants in a given string. For example, for the string "hello world", the result should be 7.

Find the Length of a String: Write a function that returns the length of a given string. For example, for the string "hello", the result should be 5.

Convert to Uppercase: Create a function that converts a given string to uppercase. For example, for the string "hello", the result should be "HELLO".

Convert to Lowercase: Write a function that converts a given string to lowercase. For example, for the string "HELLO", the result should be "hello".

Capitalize the First Letter: Create a function that capitalizes the first letter of each word in a string. For example, for the string "hello world", the result should be "Hello World".

Remove Whitespace: Write a function that removes all whitespace from a string. For example, for the string " hello world ", the result should be "helloworld".

Find a Substring: Create a function that checks if a given substring exists within a string. For example, for the string "hello world" and substring "world", the result should be true.

Replace a Substring: Write a function that replaces all occurrences of a substring within a string. For example, for the string "hello world" and replacing "world" with "there", the result should be "hello there".

Split a String into an Array: Create a function that splits a string into an array of words based on spaces. For example, for the string "hello world", the result should be ["hello", "world"].

Join an Array into a String: Write a function that joins an array of strings into a single string with a specified separator. For example, for the array ["hello", "world"] with a separator " ", the result should be "hello world".

Check if String Contains Only Digits: Create a function that checks if a string contains only numeric digits. For example, for the string "12345", the result should be true, and for "123a5", it should be false.

Find the First Non-Repeated Character: Write a function that finds the first non-repeated character in a string. For example, for the string "swiss", the result should be 'w'.

Count the Number of Words: Create a function that counts the number of words in a string. For example, for the string "hello world", the result should be 2.

Check for Anagrams: Write a function that checks if two strings are anagrams of each other. For example, "listen" and "silent" should return true.

Extract Digits from a String: Create a function that extracts all digits from a given string and returns them as a new string. For example, for the string "abc123def", the result should be "123".

Remove Duplicates from a String: Write a function that removes duplicate characters from a string while preserving the order. For example, for the string "hello", the result should be "helo".

Convert to Title Case: Create a function that converts a string to title case (first letter of each word capitalized). For example, for the string "hello world", the result should be "Hello World".

Find the Index of a Character: Write a function that returns the index of the first occurrence of a character in a string. For example, for the string "hello" and character 'l', the result should be 2.

Count Specific Character Occurrences: Create a function that counts the occurrences of a specific character in a string. For example, for the string "hello" and character 'l', the result should be 2.

Trim Leading and Trailing Spaces: Write a function that trims leading and trailing whitespace from a string. For example, for the string " hello ", the result should be "hello".

Check if String Starts with a Specific Substring: Create a function that checks if a string starts with a specific substring. For example, for the string "hello world" and substring "hello", the result should be true.

Check if String Ends with a Specific Substring: Write a function that checks if a string ends with a specific substring. For example, for the string "hello world" and substring "world", the result should be true.

Find the Last Occurrence of a Character: Create a function that finds the last occurrence of a character in a string. For example, for the string "hello" and character 'l', the result should be 3.

Convert String to Array of Characters: Write a function that converts a string into an array of its characters. For example, for the string "hello", the result should be ['h', 'e', 'l', 'l', 'o'].

Shuffle the Characters of a String: Create a function that shuffles the characters of a string randomly. For example, for the string "hello", the result could be "lhol" or any other random permutation.

Count the Number of Unique Characters: Write a function that counts the number of unique characters in a string. For example, for the string "hello", the result should be 4.

Find the Longest Word in a String: Create a function that finds the longest word in a given string. For example, for the string "The quick brown fox", the result should be "quick".

Check for Substring at Specific Index: Write a function that checks if a substring exists at a specific index in a string. For example, for the string "hello" and substring "ll" at index 2, the result should be true.

Repeat a String N Times: Create a function that repeats a string n times. For example, for the string "hello" and n = 3, the result should be "hellohellohello".

Convert a String to a Number: Write a function that converts a string representation of a number to an actual number. For example, for the string "123", the result should be 123.

Find the Average Length of Words in a String: Create a function that calculates the average length of words in a string. For example, for the string "hello world", the result should be 5.

Check if Two Strings are Equal (Case Insensitive): Write a function that checks if two strings are equal, ignoring case. For example, "hello" and "HELLO" should return true.

Remove All Digits from a String: Create a function that removes all digits from a string. For example, for the string "abc123def", the result should be "abcdef".

Find the First Word in a String: Write a function that returns the first word in a string. For example, for the string "hello world", the result should be "hello".

Check if a String is Empty: Create a function that checks if a string is empty. For example, for the string "", the result should be true.

Convert a String to a URL-friendly Format: Write a function that converts a string into a URL-friendly format (e.g., spaces replaced with hyphens, lowercase). For example, for the string "Hello World", the result should be "hello-world".

Find All Unique Words in a String: Create a function that finds all unique words in a string and returns them in an array. For example, for the string "hello hello world", the result should be ["hello", "world"].
