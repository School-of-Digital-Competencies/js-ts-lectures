## For all components

Current task is to gain skills working with the following topics

- connect fonts from https://fonts.google.com/
- download assets from Figma (export images, icons)
- css variables for colors and basic font settings
- semantics HTML (elements: ul, li, a, button, input, img)
- box-model (margin, padding, border)
